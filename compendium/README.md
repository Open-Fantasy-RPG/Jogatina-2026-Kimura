# Compendium D&D 5e

Esta pasta centraliza material de referência de regras para a campanha.

## Estrutura

- [`srd/`](srd/README.md) — conteúdo redistribuível baseado em SRD / Creative Commons.
- [`5etools/`](5etools/README.md) — referência técnica ao projeto 5e.tools, sem espelhar conteúdo comercial de livros.

## Política do repositório

O objetivo é manter aqui apenas material que possa ser redistribuído de forma clara e segura.

Conteúdo oficial de livros da Wizards of the Coast que não esteja coberto por SRD, Creative Commons ou outra licença compatível não deve ser copiado integralmente para este repositório.

Para regras específicas usadas nas fichas da campanha, prefira:

1. referências curtas e mecânicas;
2. links para fontes oficiais ou projetos externos;
3. conteúdo SRD/CC quando redistribuição for permitida;
4. notas próprias da campanha e interpretações da mesa.

## Uso com os personagens

As fichas em `personagens/` podem apontar para este compêndio para regras gerais, evitando repetir textos longos em cada personagem.
