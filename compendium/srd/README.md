# SRD / Creative Commons

Área destinada ao compêndio redistribuível de D&D 5e.

## Categorias planejadas

- classes
- espécies
- magias
- talentos
- condições
- equipamentos
- monstros
- regras gerais

## Fonte

Adicionar somente conteúdo cuja licença permita redistribuição, mantendo atribuição e avisos exigidos pela licença correspondente.

## Integração com fichas

Os documentos em `personagens/` podem referenciar arquivos desta pasta para reduzir duplicação de regras e facilitar manutenção.
