## Leitura das referências

Cada cena possui um único README com narrativa, descrição do local e referências. As imagens específicas ficam diretamente na pasta da cena correspondente, sem subpasta imagens/; outras cenas reutilizam links para o mesmo original. Ref-04 é a oficina, não a sala do segundo fundador. Ref-06 é uma visão imaginada de incêndio, não um acontecimento. Nenhuma imagem confirma por si só nome, ocupante ou planta completa.

Cada descritivo separa fatos narrados, observação visual e incertezas. Campos editáveis do mestre aceitam somente complementos já liberados aos jogadores.
