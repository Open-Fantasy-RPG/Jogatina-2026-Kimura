# A classificar

Nenhuma das 17 imagens originais de `imgs 1/` ficou sem destino: as relações de ambiente/encontro foram sustentadas pelos pixels e registros públicos. Isso não elimina as incertezas de nomenclatura e detalhes listadas no inventário.

Usar esta pasta para um novo arquivo cuja sessão/local não tenha evidência suficiente. Não forçar uma classificação apenas pelo nome do arquivo.

Para cada entrada, criar `proveniencia.md` com:
- origem pública exata e nome original;
- hash do blob e tamanho;
- observação dos pixels efetivamente vistos;
- candidatos de sessão/cena, evidências a favor e lacunas;
- confirmação necessária do mestre;
- destino definitivo após a confirmação.

Não copiar arquivos já presentes em outro destino canônico. Não importar preparação privada para tentar resolver uma classificação pública.
